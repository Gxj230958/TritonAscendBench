## Required semantics

The frozen `@triton.jit _gumbel_sample_kernel` is the gumbel-max sampler. The
grid is `(num_tokens, num_blocks)` with `BLOCK_SIZE = 1024` and
`num_blocks = ceil(vocab_size / BLOCK_SIZE)`. For each token `t` and vocab
block `b`, with `req = expanded_idx_mapping[t]`, `temp = temperature[req]`:

1. Load `logits[t, block]` (`block = b*BLOCK_SIZE + arange`, masked, `other=-inf`)
   and cast to fp32.
2. If `temp != 0` and `APPLY_TEMPERATURE`: divide logits by `temp`.
3. Cast to fp64. If `temp != 0` (gumbel path):
   - `gumbel_seed = randint(seed[req], pos[t])` (Triton Philox 4x32-10),
   - draw a fp64 uniform `u in (0, 1)` from 64 Philox bits at offset `block`
     (`tl_rand64`, clamped to the fp64 tiny so `log` stays finite),
   - add gumbel noise `-log(-log(u))` to the masked logits.
4. Masked block argmax (`tl.max(..., return_indices=True)`, ties → first index)
   writes `local_argmax[t, b] = b*BLOCK_SIZE + idx` and `local_max[t, b] = value`.

The host reduction (reproduced in `_pa_launcher.py::run`, identical to the
upstream `gumbel_sample` wrapper) then selects the winning block per token and
gathers the token id: `sampled[t] = local_argmax[t, argmax_b local_max[t]]`.

`temp == 0` is the greedy branch (argmax over the raw logits, no noise);
`temp > 0` is the gumbel-max sampling branch. Bit-exactness holds because the
Philox PRNG is reproduced exactly in the oracle (validated against
`tl.randint` / `tl.randint4x` under `TRITON_INTERPRET`).

## Inputs (driven by `_pa_launcher.py::run`)

| name | shape | dtype | dist | role |
|------|-------|-------|------|------|
| `logits` | `[T, V]` | float32 | randn | per-token vocab logits |
| `expanded_idx_mapping` | `[T]` | int64 | `gumbel_routing:R` | token → request index |
| `temperature` | `[R]` | float32 | `gumbel_temps` | per-request temp (0 = greedy) |
| `seed` | `[R]` | int64 | `randint:0:2147483647` | per-request Philox seed |
| `pos` | `[T]` | int64 | `randint:0:1024` | per-token sampling position |
| `apply_temperature` | scalar | bool | — | toggles temperature scaling (driven True) |

`gumbel_temps` pins request 0 = greedy (`temp == 0`) and request 1 = noisy
(`temp > 0`); `gumbel_routing:R` pins token 0 → request 0 and token 1 →
request 1. Together they GUARANTEE by construction that every shape routes ≥1
token through the greedy branch and ≥1 through the gumbel-noise branch, so both
kernel paths are always exercised. `apply_temperature` is driven `True` (the
richer path: temperature scaling + gumbel noise); the `False` branch only skips
the scale (a strict subset), so the constraint is honestly `== 1`.

## Output

- `sampled`: `[T]` int64 — the argmax token id sampled per token.

## Tolerance class

`sampling_rng` (bit-exact, `atol = rtol = 0`; see
`triton_ascend_bench/tolerance_policy.yaml`). Valid because the kernel is
deterministic given the seed and the oracle reproduces the Philox PRNG exactly.

## Discrimination

Fault-injection confirmed each load-bearing input is required: a kernel that
drops the gumbel noise, skips the temperature divide, ignores
`expanded_idx_mapping` routing, ignores `pos`, ignores the per-request `seed`,
or zeroes the logits all produce a different `sampled` and FAIL the bit-exact
compare.
