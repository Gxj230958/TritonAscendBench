## Required semantics

SGLang MLA decode stage1 (grouped attention over a paged latent KV cache with
fused RoPE). Per (batch `b`, query head `h`), with `num_kv_splits == 1` so the
single split spans the whole sequence:

```
score[n]            = sm_scale * (q_pe_roped . k_pe[n] + q_nope . kv_latent[n])
att_out[b,h,0,:C]   = sum_n softmax(score)[n] * v_latent[n]          # context
att_out[b,h,0, C]   = max_n score[n] + log(sum_n exp(score - max))   # log-sum-exp
```

`Q = [q_nope(C) ; q_pe(R)]`, `K_Buffer` row = `[kv_latent(C) ; k_pe(R)]`, and the
V buffer is the aliased latent slice `K_Buffer[:, 0, :C]` (the DeepSeek MLA caller
passes `val_cache_buf = key_cache_buf[..., :kv_lora_rank]`). RoPE is neox-style:
`q_pe` is rotated by `positions[b]`; the cached `k_pe` is already roped for every
token EXCEPT the last in the page, which the kernel ropes on the fly with the same
`(cos, sin)`. Mixed precision: `cos_sin_cache` is bf16 (the kernel keeps
`k_pe_last_token` at `q.dtype == bf16` across `if LAST_SPLIT:`, so a wider cos/sin
would not compile), so every `tl.dot` is bf16 × bf16 → fp32; the softmax
probabilities round to bf16 for the context dot while `e_sum` stays fp32.
