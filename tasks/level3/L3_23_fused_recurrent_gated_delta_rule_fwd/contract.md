### Reference math (oracle helper)

Gated DeltaNet recurrent fwd, transcribed in the kernel's exact update
order (decay applied to the carried state BEFORE the kS contraction; kS
uses the decayed state), state carried as S [B,H,V,K] (kernel V-major
layout). For each token t:

  S  = exp(g_t) · S                     # decay first
  kS = Σ_k (S · k_t)                    # contraction over K, decayed state
  Δ  = (v_t − kS) · β_t
  S  = S + Δ ⊗ k_t                      # rank-1 update
  o_t = scale · Σ_k (S · q_t)           # output from the updated state

q,k,v: [B,T,H,D]; g,beta: [B,T,H]; initial_state: [B,H,V,K] (D = Dv = K = V).
